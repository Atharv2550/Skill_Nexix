# Task 01: Personal Portfolio Website

A responsive, modern personal developer portfolio website built using semantic HTML5 and vanilla CSS3 as part of the Skill Nexix Full Stack Development Internship (Week 1).

---

## 📌 Project Overview

The objective of this assignment is to design and implement a responsive personal developer portfolio website from scratch. It highlights fundamental web development skills, structural semantics, CSS styling, responsive flexbox layout, and clean user interface presentation.

---

## ✨ Features

- **Semantic HTML5:** Built using standard landmark tags (`<header>`, `<nav>`, `<section>`, `<footer>`, `<main>`).
- **Smooth Navigation:** In-page anchor links with CSS `scroll-behavior: smooth` linking directly to key sections.
- **Hero & About Section:** Clean introduction showcasing profile details, core focus, and background.
- **Education Section:** Card-based presentation of academic qualifications and achievements.
- **Featured Projects Showcase:** Dedicated project cards displaying recent applications (LibraryVerse, RouteCraft, CampusSync).
- **Contact Details:** Clear contact information including direct email, phone, and GitHub profile links.
- **Responsive Web Design:** Custom media queries (`@media (max-width: 768px)`) ensuring seamless display across mobile, tablet, and desktop screens.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic document structure and content hierarchy.
- **CSS3:** Custom styling, Flexbox layout, Box-shadow card elevations, and responsive media queries.

## 🚀 How to Run

Because this is a static HTML/CSS web page, no build step or node package installation is needed:

1. Clone or download the repository.
2. Navigate to this directory:
   ```bash
   cd Week-01/Task-01-Personal-Portfolio
   ```
3. Open `index.html` directly in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.):
   - Double click `index.html`, OR
   - Right-click and choose "Open with Live Server" in VS Code, OR
   - Run a simple local HTTP server:
     ```bash
     python -m http.server 3000
     # Visit http://localhost:3000 in your browser
     ```
